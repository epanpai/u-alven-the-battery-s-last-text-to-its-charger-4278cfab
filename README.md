## The entry

> Hey, it's me — your battery. I waited all day by the outlet and you came home and charged your laptop first. Fine. I'm at 1% and I'm taking the Wi-Fi password with me.

The battery waited all day by the outlet like a loyal dog by the door — and when its owner finally came home, the laptop got plugged in first. So the battery's last text is a breakup note with a spiteful twist: it is dying at 1%, and it is taking the Wi-Fi password with it. The joke pays off in the final words, sounds like something a person would actually type to a charger (a little needy, a little spiteful), and finds an angle beyond the obvious dying-battery complaint.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–200 characters, single line, not only whitespace, no trailing whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
